## Project Context

This is the **Logios** plugin project, which integrates Hermes Agent functionality into Zotero.

### Key Files

- `src/index.ts` — Plugin entry point (sets browser globals for React in Zotero sandbox)
- `src/addon.ts` — Addon class with typed module registry
- `src/hooks.ts` — Zotero lifecycle hooks (startup, shutdown, main window load/unload)
- `src/modules/hermes/HermesClient.ts` — ACP/stdio client via Firefox Subprocess
- `src/modules/hermes/HermesApiClient.ts` — REST API client with SSE streaming
- `src/views/HermesChatView.tsx` — React 19 chat sidebar view
- `addon/manifest.json` — Plugin manifest

### Development Stack

- **Runtime**: Zotero Plugin API (Firefox 140 ESR)
- **Language**: TypeScript
- **UI**: React 19 (chat component), XUL/XHTML (native panels)
- **Build**: esbuild via zotero-plugin-scaffold
- **Toolkit**: zotero-plugin-toolkit

## Workflow

When working on this project:

1. Follow Zotero plugin conventions
2. Use TypeScript with strict mode
3. Test in a dedicated Zotero profile
4. Install as `.xpi` file via Tools → Add-ons → Install Add-on From File
5. Use `npm start` for dev server with hot reload
6. Always run `npm run build` after changes
